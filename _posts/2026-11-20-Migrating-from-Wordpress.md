## Migrating from WordPress and a new domain

Welcome to my new blog. 

My main blog used to be hosted on Wordpress as [https://garethhowell.com](https://garethhowell.com).
That made sense when I was using it for professional as well as personal content. 
Now however, I only blog on topics like Amateur Radio and Family History.
Also, Wordpress has become a bit of a pain to maintain, and I don't want to pay for hosting anymore.

So, I've move some of the posts to another one of my domains: [https://m5kvk.org](https://m5kvk.org). 
This is a domain I use for my Amateur Radio activities, and it makes sense to host my blog there.

It's hosted on GitHub Pages and uses [jekyll](https://jekyllrb.com/) to generate static pages.
This avoids the need for a database and makes it easier to maintain.

Being simpler to maintain, may even encourage me to post more often. Who knows?
